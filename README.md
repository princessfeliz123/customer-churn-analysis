# Customer Churn Analysis

## Overview

This project analyzes customer churn using SQL Server and Power BI.

The analysis focuses on identifying churn patterns across customer demographics, subscription types, contract lengths, payment delays, support calls, tenure, and other customer characteristics.

## Objectives

- Calculate the overall customer churn rate.
- Identify factors associated with customer churn.
- Analyze churn by subscription type.
- Analyze churn by contract length.
- Examine the relationship between support calls and churn.
- Analyze churn by payment delay.
- Compare customer characteristics between churned and retained customers.
- Build a Power BI dashboard to communicate the main findings.

## Tools

- SQL Server
- SQL Server Management Studio (SSMS)
- Power BI
- DAX
